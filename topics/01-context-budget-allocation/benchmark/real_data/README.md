# Benchmark 2 capture directory

Files in this directory are generated by real provider calls:

- `capture.json`: frozen public GitHub/PyPI corpus, tool-call cache, and vector-store or embedding RAG results
- `workloads.json`: candidate hashes and token totals used by the paid matrix
- `openai_resources.json`: vector-store and file IDs for explicit cleanup; absent for embedding RAG

API keys are read only from environment variables and are never written here.
Large captures and generated result ledgers should be reviewed before committing.
